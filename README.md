SelloGold Plywood - Premium Manufacturing

This is the official front-end repository for **SelloGold Plywood**, a leading manufacturer of premium marine grade plywood and durable flush doors located in Meghalaya.

🌐 **Official Website:** [https://sellogold.dpdns.org](https://sellogold.dpdns.org)

## 🎯 Project Overview
This project serves as the digital storefront for SelloGold's structural products. It is engineered to provide a fast, seamless experience for architects, interior designers, and builders looking for reliable, ISI-certified plywood materials.

### Architecture & Performance
* **Lightning Fast Delivery:** Routed through Cloudflare DNS for minimal latency.
* **Semantic HTML5:** Structured for optimal search engine crawling and indexing.
* **Responsive UI:** Tailored layouts for mobile, tablet, and desktop environments.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS
* **Interactions:** Vanilla JavaScript (Custom cursor, scroll reveals, parallax backgrounds)
* **Typography:** Google Fonts (Hanken Grotesk, Source Serif 4, Playfair Display)

## 📁 Core Pages
* `index.html` - SelloGold Homepage
* `factory.html` - Manufacturing Infrastructure Showcase
* `products.html` - Marine Grade & Flush Door Catalog
* `quality.html` - ISI Certifications & 25-Year Warranty Info
* `contact.html` - Dealer Network & Google Maps Integration
